# BlogSite
A real-time blogging platform built with FastAPI.

## Features

- Create, edit, and delete posts
- Real-time comments via WebSockets
- Live notifications for post activity
- Like posts
- JWT authentication
- Profile picture uploads via S3
- Email-based password reset
- Dark/light mode

## Tech Stack

- **Backend** — FastAPI, async SQLAlchemy, Alembic, Pydantic
- **Database** — PostgreSQL (Neon)
- **Real-time** — WebSockets
- **Storage** — AWS S3
- **Auth** — JWT
- **Email** — Brevo
- **Deployment** — Docker, Google Cloud Run
