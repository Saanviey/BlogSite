 2--some sqlalchemy queries that fetch actual data 
 The main ones you'll use:
.first() — fetches the first matching row, returns None if nothing found. Use when fetching a single item by id.
.all() — fetches every matching row, returns a list. Use when fetching multiple items.
.one() — like first but raises an exception if nothing found or if more than one result. Less common.
.count() — returns the number of matching rows, doesn't fetch the actual data.


3--auth flow 

Registration flow:
User sends username + password → `create_user` route receives it 
→ hashes the password using `hash_password` → saves username and `password_hash` to the database.
 Done, no token yet.

Login flow:
User sends username + password → `/login` route receives it →
fetches user from db by username → runs `verify_password` comparing plain password against stored hash → 
if it matches, calls `create_token` with the user's id → `create_token` signs a JWT with the user_id and expiry baked in using your SECRET_KEY → 
returns `access_token` and `token_type: "bearer"` to the client.

Accessing a protected route:
Client sends request with `Authorization: Bearer <token>` header → 
FastAPI sees `get_current_user` as a dependency on that route →
`get_current_user` pulls the token from the header → calls `verify_token` which checks the signature using SECRET_KEY and reads the user_id from the payload →
uses that user_id to fetch the user from db → returns the user object to your route → 
your route now has the current logged in user and does its thing.

The chain in one line:
request → route → get_current_user → verify_token → SECRET_KEY → user_id → db → user object → route logic.

4--
 Depends(some_function) means "run this function first and give me whatever it returns."
ex:
Depends(get_db) — run get_db, give me the session it returns
Depends(get_current_user) — run get_current_user, give me the user it returns

The variable name on the left is just what you call it inside your route:
db: Annotated[AsyncSession, Depends(get_db)]  # db = whatever get_db returns
current_user: Annotated[models.User, Depends(get_current_user)]  # current_user = whatever get_current_user returns
